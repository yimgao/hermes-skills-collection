# Difficult Conversation Coach — 高难度对话教练

> 你有过一次对话，是在脑子里反复演练了 10 遍、真正开口时却一句都没说对的吗？本 skill 把"想说的话"变成"能落地的战术"：先解剖局势 → 选沟通框架 → 起草 30 秒开场 → 预测对方 5 种反应 → **陪你把这场对话真实演练一遍**（AI 扮演对方，逐级加压）→ 输出一张可打印的"对话卡片"。
>
> **它不代写消息（那是 `message-tone-adjuster` / `email-composer` 的活）——它负责让你在真正开口前，已经赢过一次。** 演练质量取决于你提供的情报细节，越具体越致命。

| Capability | Description |
|-----------|-------------|
| 🧭 局势解剖 | 8 问情报收集：关系史、触发点、你要什么、对方要什么、最坏情况、情绪状态、渠道、可谈/不可谈 |
| 🧰 框架库 | DEAR MAN（DBT 人际效能）/ NVC（观察-感受-需要-请求）/ SBI（情境-行为-影响）/ Radical Candor / 利益型谈判（BATNA） |
| 🎯 30 秒开场脚本 | 把"开场白"写成脚本——开场决定整场对话的走向，绝不即兴 |
| 🎭 多轮角色扮演 | AI 扮演对方，逐级加压 L1→L5（困惑→反驳→道德绑架→发怒→最坏情况），你实战练习 |
| 🛡️ 反对意见预演 | 预测对方最可能的 5 句反击，配好既定的应答话术 |
| 🌡️ 情绪降级话术 | 暂停句（"我们先停一下"）、破唱片法（broken record）、灰石法（gray rock）、何时离场 |
| 📋 对话卡片 | 可打印一页：开场句 + 3 个核心点 + 3 个应对 + 降级话术 + 退场句 |
| 🔄 事后复盘 | 对话后回填：哪些话管用、哪些翻车、要不要发跟进消息修复关系 |
| 🔒 本地执行 | 全程不调用外部服务，敏感的家庭/职场对话内容不出本机 |

## When to Use

- *"我要跟老板谈加薪，不知道怎么开口，怕被拒绝后很尴尬"*
- *"我想辞职，但老板人不错，怎么说才能不撕破脸？"*
- *"我要给一个总是迟交的下属做批评性反馈，帮我演练一下"*
- *"我妈老是干涉我带孩子的方式，我想立个边界又不想吵架"*
- *"室友从来不洗碗，我忍了三个月了，怎么开口？"*
- *"我想跟交往两年的对象谈分手，怎么谈伤害最小？"*
- *"我朋友借钱一直不还，我要催但又想保住这段关系"*
- *"我要告诉团队项目要延期了，怎么传达坏消息？"*
- *"我上次说错话伤了同事，想道歉——帮我设计这场对话"*
- *"客户一直在压价，我要拒绝，帮我模拟他怎么反驳，我练几轮"*
- *"Help me rehearse asking my landlord to fix the mold — he keeps ignoring me"*
- *"我下周要做一场绩效面谈，如果员工情绪崩溃/发火我该怎么应对？"*

## Core Workflow

### Step 1: 情报收集 —— 局势解剖（8 问）

拿到任意"难谈的事"后，先完成情报收集，**不要跳过直接给话术**。缺信息的项主动追问，或用合理默认并标注。

```markdown
1. 对方是谁？       → 关系（老板/伴侣/父母/室友/下属/客户）+ 相处了多久 + 权力差
2. 触发点是什么？   → 这次非谈不可的导火索（一句话，具体事件而非积怨）
3. 你要的是什么？   → 理想结果 / 可接受结果 / 底线（三档）——区分"必需"和"想要"
4. 对方要的是什么？ → 从他的角度看，他为什么这么做？（猜测也要写）
5. 最坏情况？       → 你最怕对方说什么/做什么？最坏会怎样？
6. 情绪温度？       → 你现在的状态（愤怒/委屈/焦虑）+ 对方可能的情绪
7. 渠道与场合？     → 面谈 / 电话 / 文字？私下 / 公开？时间够不够？
8. 你的退路（BATNA）？→ 如果谈崩，你还有什么选择？（没有退路=谈判权弱，先补退路）
```

**同时做"关系温度计"判断**：这段关系是**一次性的**（谈完就散，如客户、陌生人）还是**长期持续的**（家人、同事、伴侣）？长期关系优先"保住关系 + 解决问题"，一次性关系可以更直接。

### Step 2: 策略设计 —— 选框架、起开场、摆预案

根据 Step 1 结果选择框架（可混用），并起草开场脚本。

| 框架 | 全称 / 结构 | 最适合 |
|------|------------|--------|
| 🧩 **DEAR MAN** | Describe 描述事实 → Express 表达感受 → Assert 明确请求 → Reinforce 强化好处（+ Mindful 不跑题 / Appear confident / Negotiate 可谈） | 提要求：加薪、要资源、立边界 |
| 💚 **NVC** | Observation 观察（不带评判）→ Feeling 感受 → Need 需要 → Request 请求（具体可执行） | 情感类冲突：伴侣、家人、朋友 |
| 🎯 **SBI** | Situation 情境 → Behavior 行为 → Impact 影响 | 给下属/同事做批评性反馈 |
| 🌱 **Radical Candor** | Care Personally 真诚关心 + Challenge Directly 直接指正 | 管理者给反馈、上下级 |
| ⚖️ **利益型谈判** | 立场（position）→ 背后利益（interest）→ 创造双赢选项 → 用 BATNA 撑底 | 任何有利益博弈的对话：加薪、压价、延期 |

**开场脚本公式**（30 秒内说完，绝不即兴）：

```text
【缓冲/联结 1 句】+【事实描述 1 句，不带情绪】+【你的感受/立场 1 句】+【明确请求 1 句】+【给对方回应空间 1 句】

示例（加薪）：
"谢谢你抽时间。我想聊聊我的职位和薪酬（缓冲）。
过去一年我带了 3 个项目、把交付周期缩短了 30%（事实）。
我希望能在这个基础上把薪资调整到 X（请求）。
想先听听你怎么看现在的范围和节奏（留空间）。"
```

**预测对方反应**：列出对方最可能的 5 句话（含最扎心那句），每句配好**既定应答**。不要临场发挥——反击台词已经写好了。

| 对方可能说 | 你的应答方向 |
|-----------|-------------|
| "现在预算紧张" | 不接"没预算"的框架 → 转向"那我们先约定 6 个月后的评估标准" |
| "别人都没提" | 我陈述的是我的价值和市场数据，不比较个人 |
| "你太敏感了" | 回到事实："我说的具体行为是 X，它带来的影响是 Y" |
| "你要这么想我也没办法" | 不接情绪球 → "我不是要吵赢，我是想解决那天的事" |
| （沉默/哭） | 暂停 → "我们可以先停 5 分钟，你想好了再继续" |

### Step 3: 模拟演练 —— 多轮角色扮演（核心）

**这是本 skill 的杀手锏。** AI 扮演对方，你扮演自己，逐轮加压。每一轮后 AI 给即时教练反馈。

```text
回合编排（Round 1 → 5）：
L1 困惑/拖延   "怎么突然说这个？"/"回头再说吧"        → 练：稳住节奏，不跑题
L2 反驳/比较   "别人怎么没提？"/"你上次也……"          → 练：回到事实和你的请求
L3 道德绑架     "你这样让我很为难 / 我为你付出这么多"   → 练：共情但不退让（同理心 ≠ 让步）
L4 发怒/指责   "你怎么这么不懂事/自私！"               → 练：降级话术、不接情绪球
L5 最坏情况     威胁 / 哭 / 冷暴力 / "那算了"           → 练：暂停、退场、保留关系垫层
```

**降级话术速查（随时可用）：**

| 情境 | 话术 |
|------|------|
| 对方情绪上头 | "我听得出来你现在很生气，我不想让这次谈话变成争吵。我们先停 10 分钟好吗？" |
| 对方反复绕圈 | 破唱片法：重复同一句核心请求，不加入新论点 |
| 对方人身攻击 | 灰石法：平淡回应，不提供情绪燃料——"我听到你的意思了，我们回到具体的事" |
| 对方沉默/逃避 | "我可以给你时间想，但这件事我需要一个答复——我们约周五中午前？" |
| 需要体面退场 | "今天先到这儿，我不想在情绪里下结论。我明天再找你，我们重新谈。" |

**AI 演练输出格式**（每轮）：

```markdown
### 🎭 Round N (Level N: 类型)
**对方（角色扮演）:** "……"
**你的回应:** （用户在此输入，或让 AI 提示 2 个可选打法）

### 🧑🏫 教练复盘
- ✅ 做得好的：
- ⚠️ 可改进的：
- 🔁 建议改写：
### 📈 本轮评分：X/5（立场清晰 / 情绪稳定 / 不跑题 / 守住底线）
```

## Example Invocations

### Example 1: 跟老板谈加薪（DEAR MAN + L1–L5 演练）

**用户**: 我在公司干了 2 年，业绩不错但一直没涨薪，想找老板谈。帮我准备一下，顺便模拟他会怎么拒绝。

**Agent**:

```markdown
## 1. 情报确认
- 对象：直属老板（相处 2 年，你是核心执行者）
- 触发点：年度调薪期临近，同期新人薪资倒挂
- 你要的：理想 +15%，可接受 +10%，底线 +8% 或书面约定 6 个月后评估
- 对方要的：控制预算、留人但不涨成本
- 最坏情况：他打太极"再等等"或说"公司困难"
- 退路（BATNA）：手里有 1 个外部 offer 意向 → 谈判权↑

## 2. 30 秒开场（DEAR MAN）
"谢谢您抽时间。我想聊聊我的薪酬（Describe）。
过去两年我独立交付了 A/B/C 三个项目，把维护成本降低了约 25%（Express+事实）。
我希望能把薪资调整到 X，这符合我当前的市场价值（Assert）。
如果能谈拢，我可以承担下季度 D 项目的技术负责人（Reinforce）。"

## 3. 预测 5 个反击
| 他会说 | 我答 |
|--------|------|
| 预算冻结了 | "理解。那我们把数字写进 Q4 评估，若达标就调，可以吗？" |
| 你才来两年 | "我不是比工龄，我是比交付结果和市场价。" |
| 再等等看 | "可以等，但需要一个明确的时间点和标准。" |
| 公司现在不容易 | "我理解，所以我愿意用业绩换——请给我一个可量化的路径。" |
| 你这是要挟？ | "不是，我在做职业规划。我希望能在这里继续成长。" |

## 4. 现在开始演练 —— Round 1 (L1 拖延)
**老板（角色扮演）:** "怎么突然想聊这个？我一会儿还有个会。"
**轮到你了** —— 试着用你的开场，稳住节奏不跑题。（输入你的回应，或让我给你 2 个可选打法）
```

### Example 2: 给经常迟交的下属做批评性反馈（SBI）

**用户**: 我团队里有个成员连续三次迟交，我要给他反馈，但不想打击他。

**Agent**:

```markdown
## SBI 脚本
- **Situation（情境）:** "上周三的季度报告，约定中午 12 点前给我。"
- **Behavior（行为）:** "你实际在下午 4 点交，而且前两次也是类似情况。"
- **Impact（影响）:** "这导致我和 CFO 的沟通要临时改期，也让我没法在承诺的时间给到下游。"
- **请求:** "接下来两次交付，能不能提前一天给我初稿？这样我也有缓冲。"

## 开场（Radical Candor：先关心再直接）
"我一直很认可你的分析质量（Care）。有个具体的事想跟你对齐（Challenge）……"

## 演练 Round 1 (L3 道德绑架)
**下属（角色扮演）:** "我最近家里事很多，你是不是不理解我？"
**你要练的是**：共情但守住标准 —— "我理解你最近很难，我也愿意帮你调整节奏；但交付时间是承诺，我们能不能一起定个现实的新时间？"
```

### Example 3: 立边界 —— 父母干涉育儿（NVC + 降级）

**用户**: 我妈总说我不该让孩子自己吃饭弄得一团糟，每次都要插手，我烦死了但又不想跟她吵。帮我准备怎么跟她说。

**Agent**:

```markdown
## 1. 关键判断：长期关系 → 优先"保住关系 + 立住边界"，不追求"吵赢"
## 2. NVC 脚本
- **Observation:** "妈，这两天孩子吃饭的时候，你都会过来喂他。"（不带评判）
- **Feeling:** "我有点着急，也有点被否定。"
- **Need:** "我希望按我们自己商定的方式带他，让他练习自己吃。"
- **Request:** "下次他吃得乱的时候，你能不能先让我试试？"

## 3. 演练 Round 3 (L3 道德绑架)
**妈（角色扮演）:** "我辛辛苦苦帮你带孩子，你还嫌我多事？"
**降级 + 守边界:** "妈，你的帮忙我特别感激，没有你我真撑不下来（共情）。只是吃饭这件事我想自己来，其他的都听你的（划清范围，不全盘否定）。"
```

## Common Pitfalls

| 问题 | 解决方案 |
|------|---------|
| 直接跳过情报收集，上来就要话术 | 8 问必须走完；缺信息主动追问，最坏情况和 BATNA 尤其不能漏 |
| 把"同理心"理解成"让步" | 共情 ≠ 同意。话术模板："我理解你的感受 + 但我的立场是X" |
| 开场即兴发挥 | 开场必须写成脚本背下来；第一句决定整场走向 |
| 一次对话想塞 3 件事 | 一次对话只解决一个核心问题，其余另约时间 |
| 对方情绪化时讲逻辑 | 先降级（暂停/共情），情绪不下去时讲逻辑=火上浇油 |
| 没有底线和退路 | 谈之前先定三档结果（理想/可接受/底线）+ BATNA，否则容易被带偏 |
| 只准备"我要说什么"，不准备"他会怎么回" | 必须预演对方 5 句反击，反击台词提前写好 |
| 长期关系里追求"赢" | 家人/同事/伴侣优先关系修复 + 问题解决；赢一场输一段关系是亏的 |
| 把演练当走过场 | 至少练到 L3；只在 L1 通过就上真战场=没准备 |
| 忽略渠道 | 分手/辞职/严重冲突尽量面谈或语音，文字易误读、易留证据 |

## Verification Checklist

- [ ] 8 问情报收集完成（或明确标注了合理默认）
- [ ] 区分了长期关系 vs 一次性关系，并调整策略
- [ ] 选定了沟通框架并说明选择理由（DEAR MAN / NVC / SBI / Radical Candor / 利益型）
- [ ] 30 秒开场脚本已写成逐字稿
- [ ] 预测了对方 ≥3 个（最好 5 个）反击并配好既定应答
- [ ] 定义了理想 / 可接受 / 底线三档结果 + BATNA
- [ ] 完成至少 3 轮（L1–L3）角色扮演演练，含教练复盘
- [ ] 输出可打印的对话卡片（开场+核心点+反击应答+降级话术+退场句）
- [ ] 提供了谈成后跟进 / 谈崩后修复消息的模板
- [ ] 全程无外部 API 调用，敏感内容不出本机

## Data Sources & Accuracy

- **框架来源**：
  - **DEAR MAN** 出自 DBT（辩证行为疗法，Marsha Linehan）的人际效能模块，公开通用结构。
  - **NVC（非暴力沟通）** 出自 Marshall Rosenberg，四要素 Observation–Feeling–Need–Request。
  - **SBI / Radical Candor** 是通用管理反馈模型（Center for Creative Leadership / Kim Scott），广泛用于职场。
  - **利益型谈判 + BATNA** 出自 Fisher & Ury《Getting to Yes》与哈佛谈判项目。
- **角色扮演性质**：AI 扮演的"对方"是基于你描述的**拟真模拟**，用于练习与压力测试，**不代表真实对方的真实反应**。真实对话请保留灵活性。
